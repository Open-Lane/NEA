| Mistake                                     |   Wrong code                                             |   Correct code                                                                       |   Why it doesn’t work                                                                                           |
| ------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Page tables not aligned**                 | `asm pagel4: resb 4096`                                  | `asm align 4096 \| pagel4: resb 4096`                                              | CPU requires page tables aligned to 4096 bytes. Misaligned → triple fault when enabling paging.                  |
| **GDT not loaded before long mode jump**    | `asm jmp gdt64.code:long_start`                          | `asm lgdt [gdt64.pointer] \| jmp gdt64.code:long_start`                            | Without loading GDT, CPU has invalid segment descriptor → crash on jump.                                         |
| **Using elf64 but wrong mode assumptions**  | `asm bits 64 \| start: mov rsp, stack_top`             | `asm bits 32 \| start: mov esp, stack_top`                                         | CPU starts in 32-bit protected mode from Multiboot. Using 64-bit instructions before long mode → invalid opcode. |
| **Page tables not identity mapping memory** | `asm mov [pagel2], eax`                                  | `asm mov eax, ecx \| shl eax, 21 \| or eax, 0x83 \| mov [pagel2 + ecx*8], eax` | If kernel address isn't mapped, CPU enables paging then can't fetch next instruction → triple fault.             |
| **Multiboot header not first in binary**    | `ld .boot : { KEEP(*(.multiboot_header)) } \| . = 1M;` | `ld . = 1M; \| .boot : { KEEP(*(.multiboot_header)) }`                             | GRUB scans first 8 KiB only. If header later → kernel not recognised.                                            |
| **PAE not enabled before paging**           | `asm mov cr3, eax \| mov cr0, eax`                     | `asm mov eax, cr4 \| or eax, 1 << 5 \| mov cr4, eax`                             | Long mode requires PAE. Without it → paging enable causes triple fault.                                          |
| **Long mode not enabled in EFER MSR**       | `asm mov cr0, eax`                                       | `asm mov ecx, 0xC0000080 \| rdmsr \| or eax, 1 << 8 \| wrmsr`                  | This sets Long Mode Enable bit. Without it → CPU stays in 32-bit paging mode.                                    |
| **GDT missing 64-bit code segment**         | `asm gdt64: dq 0`                                        | `asm gdt64: dq 0 dq (1<<43) \| (1<<44) \| (1<<47) \| (1<<53)`    | Long mode requires special 64-bit code segment descriptor.                                                       |
| **Stack used before initialized**           | `asm call setup_tables`                                  | `asm mov esp, stack_top \| call setup_tables`                                      | CALL uses stack. Uninitialized stack corrupts memory → crash.                                                    |
| **Wrong far jump after enabling paging**    | `asm jmp long_start`                                     | `asm jmp gdt64.code:long_start`                                                      | Must reload CS using far jump to activate 64-bit segment.                                                        |
